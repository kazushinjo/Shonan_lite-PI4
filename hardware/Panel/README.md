# 5インチLCD用パネル(ケース前面ベゼル)

5インチLCDを取り付けるケース前面のパーツです。窓の縁から外形までの幅(前面から見たベゼルの縁)は上下左右とも 15 です。4隅のボスに M3 インサートナットを入れ、裏ぶたをネジで止めます。単位は mm です。

## ファイル

| ファイル | 内容 |
|---|---|
| `5_in_lcd_case_front_bezel15.scad` | OpenSCAD のデータ。外形・窓・壁・ボス・穴をすべてパラメータで作る |
| `LCDケース前面_図面_M3インサート.pdf` | 取り付け図(日本語) |
| `LCD_case_front_drawing_M3_insert_EN.pdf` | 取り付け図(英語) |

## 主な寸法

| 項目 | 寸法 | 説明 |
|---|---|---|
| 外形 | 141.55 × 98.29 × 8 | 角 R1、前面の外周 C1 |
| ベゼルの縁 | 上下左右とも 15 | 窓の表面側の縁から外形まで(奥側の縁からは 16) |
| 内壁 | 138.55 × 95.29 | 壁厚 1.5、前面の板の厚さ 1.5 |
| 窓 | 表面側 111.55 × 68.29 / 奥側 109.55 × 66.29 | C1 の面取り。v18+2mm と同じ大きさ |
| ボス | φ6.62 × 4か所 | 4隅で縦横の内壁に接し、隅側は壁と一体 |
| インサート穴 | **φ5.0 深さ5** | **M3 インサートナット用**。ボス上面(Z=8)から |
| 穴ピッチ | **131.93 × 88.67** | 外形の端からボス中心まで 4.81 |

ボスの肉厚は窓側で 0.81 です。

## OpenSCAD のパラメータ

ファイル先頭の値を変えると作り直せます。

| 変数 | 値 | 内容 |
|---|---|---|
| `bezel_x` | 15 | 左右の縁の幅 |
| `bezel_y` | 15 | 上下の縁の幅 |
| `hole_d` | 5 | 穴径 |
| `hole_depth` | 5 | 穴の深さ(ボス上面から) |
| `boss_d` | 6.62 | ボス外径 |
| `wall_gap` | 0 | 壁とボスのすき間(0 で壁に接し、隅を埋める) |

外形と穴ピッチは縁の幅・ボス径・`wall_gap` から決まり、レンダリング時にコンソールに表示されます。OpenSCAD 2021.01 でレンダリングできることを確認しています。
