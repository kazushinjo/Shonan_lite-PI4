# 5インチLCD用パネル(ケース前面ベゼル)

5インチLCDを取り付けるケース前面のパーツです。4隅のボスに M3 インサートナットを入れ、裏ぶたをネジで止めます。単位は mm です。

## ファイル

| ファイル | 内容 |
|---|---|
| `5_in_waveshare_lcd_a_case_front_v18+2mm_hole5x5_corner.scad` | OpenSCAD のデータ。元の STL(v18+2mm)を polyhedron として埋め込み、ボスとインサート穴を作り直している |
| `LCDケース前面_図面_M3インサート.pdf` | 取り付け図(日本語) |
| `LCD_case_front_drawing_M3_insert_EN.pdf` | 取り付け図(英語) |

## 主な寸法

| 項目 | 寸法 | 説明 |
|---|---|---|
| 外形 | 124.27 × 97.33 × 8 | 角 R1、前面の外周 C1 |
| 内壁 | 121.27 × 94.34 | 壁厚 1.5、前面の板の厚さ 1.5 |
| 窓 | 奥側 109.55 × 66.29 / 表面側 111.55 × 68.29 | C1 の面取り |
| ボス | φ6.62 × 4か所 | 4隅で縦横の内壁に接し、隅側は壁と一体 |
| インサート穴 | **φ5.0 深さ5** | **M3 インサートナット用**。ボス上面(Z=8)から |
| 穴ピッチ | **114.65 × 87.72** | 外形の端からボス中心まで 4.81 |

ボスの肉厚は窓側で 0.81 です。

## OpenSCAD のパラメータ

ファイル先頭の値を変えると、ボスと穴を作り直せます。

| 変数 | 値 | 内容 |
|---|---|---|
| `hole_d` | 5 | 穴径 |
| `hole_depth` | 5 | 穴の深さ(ボス上面から) |
| `boss_d` | 6.62 | ボス外径 |
| `wall_gap` | 0 | 壁とボスのすき間(0 で壁に接し、隅を埋める) |

穴ピッチはボス径と `wall_gap` から決まり、レンダリング時にコンソールに表示されます。OpenSCAD 2021.01 でレンダリングできることを確認しています。
